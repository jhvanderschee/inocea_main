{{- /* Link render hook. Plain, predictable anchors, and deliberately no `class` or `id` — those arrive from a kramdown-style attribute list written after the link: [Get started now](/get-started/){:.button} A render hook only ever sees its own node, so it cannot read the text that follows it. `inline_attributes.html` moves that `{: … }` onto the anchor once the paragraph is html; this file's job is to guarantee the shape that pass expects to find. A link whose destination is a local raster image — the lightbox pattern, `[![](/photo.jpg)](/photo.jpg)` — gets a resized webp rendition instead of the full-weight original, mirroring what the gallery shortcode links to. A link that leaves the site opens in a new tab. "Leaves the site" is read off the destination: an absolute `http(s)` url that does not start with our own baseURL. Relative links, anchors, `mailto:` and `tel:` stay in place — a new tab for those only ever leaves an empty one behind. @context {link} . @returns {string} one */ -}} {{- $href := .Destination -}} {{- $external := and (hasPrefix (lower $href) "http") (not (hasPrefix $href site.BaseURL)) -}} {{- with resources.GetMatch $href -}} {{- if and (eq .ResourceType "image") (ne .MediaType.SubType "svg") -}} {{- $href = (.Fit "1600x1600 webp q50").RelPermalink -}} {{- end -}} {{- end -}} {{ .Text }} {{- /* no trailing newline: a render hook writes inline content */ -}}
